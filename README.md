# 透视镜 · X-Ray Mirror

打开摄像头，实时看到自己身体里的骨骼和器官。所有骨骼、器官模型都由代码在页面加载时生成（SDF 建模 + Surface Nets 网格化），不加载任何模型文件。

> 在线体验：https://x.botlearn.ai/xray-mirror/ （无需验证码）
>
> 原作：drainkidgg-bot/jins-xray（经原作者同意公开）。本仓库在原作基础上，在首页顶栏加了「1 · 手部识别」「2 · 动作识别」两个入口，指向 `xray-hand/` 里两个独立页面（由 X 光之手拆出，见 `xray-hand/README.md`），与透视镜代码分开。
>
> 仅供个人学习演示，不作商业用途；猫狗识别用的 AP-10K 动物姿态模型授权偏学术研究用途。

## 运行

```bash
python3 serve.py
```

然后用 Chrome 打开 http://localhost:5178 ，点「开启摄像头」。没有摄像头时可以点「先看演示」。

## 操作

| 按键 | 作用 |
| --- | --- |
| 1 / 2 / 3 / 4 | 切换风格：X 光 / 黏土 3D / 像素 HD-2D / ASCII |
| B / O | 显示或隐藏 骨骼 / 器官 |
| L | 显示或隐藏 自动标注 |
| M | 镜像开关 |
| P | 切换同时识别的人数（1 / 2 / 3） |
| A | 开关猫狗识别 |
| V | 全身 / 透镜 |
| F | 全屏 |

把鼠标移到任意骨头或器官上，会显示它的中英文名称和一句科普。

最多同时识别 3 个人，每人一副独立的骨骼。底部「人数」可以调小：只有一个人时选 1 最流畅。

还能识别猫和狗（最多 2 只），叠加四足动物骨骼：猫/狗头骨、7 节颈椎、13 节胸椎和 13 对肋骨、7 节腰椎、会摆动的尾椎、肩胛骨、骨盆和四肢。侧面和斜侧面效果最好；正面趴着时只显示头骨和前腿。

## 界面层级

- **顶部：模式**（在干什么）——「展示」自由探索，默认；「课程」按步骤上课。
- **底部：看法**（怎么看）——「全身 / 透镜」和四种风格属于同一层，只在展示模式里有「全身 / 透镜」。

**透镜**：只有圆形透镜里面显示骨骼，外面是同一风格滤镜下的画面（不显示骨骼、稍暗一点），两者之间是一圈柔和的渐变，外面再画一条很细的圆线；X 光风格下透镜里也能隐约看到真人。透镜跟着手掌走，手离镜头越近透镜越大；画面里没有手时停在脸上；移动鼠标时跟着鼠标。标注也只标透镜里看得见的部分。四种风格都能用。

## 课程模式

顶部可以在「展示」和「课程」之间切换，默认是展示模式（自由探索）。课程模式目前有一课：

**课程 01 · X 光之手**（约 3 分钟，只看一只手）

1. 显影：哪个关节动了，它两头的骨头就亮起来，点亮 20 块
2. 腕骨点名：手腕放大到「灯箱」上，用食指指尖（或鼠标）停在骨头上，认出剩下 7 块腕骨
3. 骨头手势：比个耶、比个 OK、数字六、握拳，摆对了对应手指的骨头变色
4. 拍片子：27 块骨头逐个编号，生成一张可以保存的胶片卡

课程里四种风格照常可以切换，点顶部「展示」或按 Esc 退出课程。没有摄像头时，课程会用一只合成的手自动演示全程。
课程的环节设计参考了同事做的「X 光之手」小课，画面和骨骼全部用本站自己的引擎重做。

## 结构

- `src/sdf.js` 距离场建模工具与网格化（含烘焙环境光遮蔽）
- `src/models/` 头骨、躯干、四肢、手骨、内脏的模型定义
- `src/rig.js` 用人体关键点驱动骨骼
- `src/tracker.js` MediaPipe 面部 / 手 / 姿态追踪与去抖（每个人单独裁剪画面跑一个姿态模型）
- `src/people.js` 把识别到的脸、手、身体归属到各自的人
- `src/animals.js` 猫狗检测与 17 个动物关键点（MediaPipe 物体检测 + RTMPose AP-10K，经 ONNX Runtime Web 运行）
- `src/animalrig.js`、`src/models/quadruped.js` 四足骨骼的建模与驱动
- `src/render.js` 渲染管线与四种风格
- `src/lens.js` 透镜跟随（手掌 / 脸 / 鼠标）
- `src/labels.js`、`src/anatomy.js` 标注与科普内容
- `src/lesson/` 课程模式：`hand-data.js` 课程内容（骨头、关节、题目、手势、文案），`lesson.js` 课程流程，`handmath.js` 关节角度与手势判断，`film.js` 胶片卡与音效
- `vendor/`、`models/` 本地化的 three.js、MediaPipe、ONNX Runtime 及各追踪模型（离线可用）

## 第三方模型

动物姿态模型来自 OpenMMLab 的 RTMPose（AP-10K 数据集训练）。AP-10K 数据集的授权偏向学术研究用途，如果要把这个 demo 用于商业场合，请先确认该模型权重的使用许可。
